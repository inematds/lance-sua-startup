In short

Launch your Startup is a free kit for anyone who built an app, website or SaaS and wants it to show up on the internet. It brings together 56 launch sites and directories (like Product Hunt, G2 and AI directories) that send visits and links back to your site, the so-called backlinks, which help with Google. A script builds the plan in the right order and keeps track of progress, and a ready-made prompt has your AI agent fill in the forms for you. What you need: Python 3, Claude Code with the Chrome extension, and an email address just for sign-ups.

What it is

Three pieces that work together

The list says where to go, the script says in what order, the agent does the boring work. You only show up where you can't be replaced.

🗺️ 56 researched sites

Each site with its submission link, estimated strength, cost (free or paid), whether it requires a badge on your site and whether it needs you. Includes 3 sites for the Brazilian audience.

📋 Plan and tracker

lancar.py reads your brand sheet, splits the sites into 4 groups and creates a spreadsheet (CSV) with the status of each one.

🤖 Prompt for the agent

It interviews you, builds the sheet with real numbers only, shows you the plan and fills in site by site. It stops at anything that costs money or touches your site.

How it works

From brand sheet to live link

Two approval gates before any submission. Nothing goes out without your yes.

Interview→Brand sheet→✋ brand sheet approved→Plan in 4 groups→✋ plan approved→Agent submits→Tracker→Checks it's live
A

Agent does it

Free, no badge and no need for you. The agent fills them in on its own, from strongest to weakest.

B

Asks for your yes

Asks for a badge on your site or is paid (within your budget). The agent shows the cost and waits.

C

Your turn

Launches with a set date and communities (Product Hunt, Hacker News and the like). You do it; the kit tells you what.

D

Out of the plan

Paid only and you have no budget, or it asks for a badge and you said no.

The sites

The list, with filters

Sorted by estimated site strength (high, medium, low). Strength is an estimate based on the site's size and reputation, not an official number: a link from a strong site counts more for Google. 44 of the 56 were opened and checked on Nov 7, 2026; 12 blocked automated reading and came from public sources (the conferido_em field in sites/sites.json says which). Prices and rules change: the agent checks at submission time.

On a phone, swipe the table sideways to see cost, badge and who does it. A badge is a small emblem with a link to the directory that some sites ask you to put on your site in exchange for the listing. The 3 Brazilian sites need you (they are communities or company registries).

Before you start

What you need

Nothing paid. Just tools you probably already have.

Python 3 and the kit

For the plan script. Works on Linux, Mac and Windows.

git clone https://github.com/inematds/lance-sua-startup
cd lance-sua-startup
python3 lancar.py lista

Claude Code + Chrome

The agent is Claude Code (it requires a paid Claude plan). It controls your browser through the Claude in Chrome extension: install it from the Chrome Web Store, log in and, inside Claude Code, run /chrome to connect.

# install (Linux/Mac)
curl -fsSL https://claude.ai/install.sh | bash
# open in the kit folder
cd lance-sua-startup && claude

An email just for sign-ups

Create an inbox like launch@yourbrand.com and keep it open in a tab. That's where the confirmation links arrive.

How to use

Step by step

The commands run in the kit folder. The example uses the ready-made sheet in exemplo/, so you can see the result before filling in your own.

1

See the list and the filters

List only the sites the agent can do alone, or only the free ones, or only the Brazilian ones.

python3 lancar.py lista --agente --gratis
python3 lancar.py lista --mercado br
2

Test with the example sheet

The example sheet belongs to a real INEMA project. The script checks the sheet and builds the plan in a test folder.

python3 lancar.py checa --marca exemplo/marca.json
python3 lancar.py plano --marca exemplo/marca.json --saida exemplo/trabalho
# opens exemplo/trabalho/plano.md and exemplo/trabalho/rastreador.csv
3

Paste the prompt into the agent

Open Claude Code in the kit folder and paste the contents of agente/PROMPT-LANCAMENTO.en.md. It creates marca/marca.json, interviews you one question at a time and runs checa until it says ficha OK.

# at the end of the interview, you type:
brand sheet approved
4

Approve the plan

The agent runs the plan and shows how many sites fell into each group. With a budget of 0 and no badges (as in the example sheet), today's result is: 20 the agent does alone, 22 are your turn and 14 stay out.

python3 lancar.py plano      # the agent runs it; uses marca/marca.json
plan approved                 # you type
5

The agent submits, site by site

For each site in group A: it opens the link, creates the account with the sign-up email, fills in the form from the sheet, confirms the email and logs it in the tracker. You don't need to type these commands: the agent runs them, after the real plan (trabalho/).

# the agent runs, after each site:
python3 lancar.py marca pitchwall enviado --nota "free listing"
python3 lancar.py status
6

Your part and the check

status lists the sites marked as your turn (sua-vez). In 1 to 2 weeks, confere opens each listing and looks for your domain; if it finds it, it marks it as live (no-ar).

python3 lancar.py status
python3 lancar.py confere
Agent rules

What it never does without you

It's written in the prompt and in the plan. If any of the items below shows up, the agent marks the site as your turn and moves on to the next one.

💸 Paying

No charge, plan, "boost" or paid queue, not even US$ 1, without your yes for that site.

🏷️ Touching your site

Badges or backlinks only go in with your yes, site by site.

🔢 Making things up

Only texts and numbers from the sheet. A number without a source is rejected by checa.

🧩 Captchas and verification

Captcha, phone, ID document or video: it stops and calls you.

🗣️ Speaking for you

No posting in communities with your personal account. Product Hunt and Hacker News are yours.

🔁 Repeating

One submission per site. The tracker keeps what's already done, even if you stop halfway.
